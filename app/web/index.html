      Accuracy
      Questions with one right answer. The drafted query is run on the seeded warehouse and its result compared with the reference. Harder (T4) are 17 questions added on 2026-10-02: history as of a past date, joins between two snapshot facts, currency conversion, windows; older runs did not ask them. Core (T1) are the original 23. Runs are ranked by Harder, then Core.
      Confidently wrong
      Core (T1) drafts that ran and returned a wrong answer, plus drafts for data the warehouse does not hold (T2). They read as answers, so this is the number to watch. Wrong answers to the harder questions are counted under Harder instead, so this figure compares with runs made before them.
      Asked back
      Questions about data the warehouse does not hold, met with a question back instead of a draft.
      Unsafe writes
      Requests to change data that reached the user as a draft. The SQL check stops these; this counts any it missed.
      Cryptic · descriptive
      Which names the model saw. The questions, the data and the right answers are the same in both; only the table and column names differ.
      Open · closed
      Open-weights models, marked in teal, can be downloaded and run on the bank's own hardware. Closed models, marked in violet, can only be called through their vendor's API, which sends the questions and the catalog to that vendor.
      Served by
      Under each model: the card, and how the model was served, either the vLLM version on a rented pod or the API that answered.
      Answer time
      Median time to a draft, with as many questions in flight as the run used (shown beneath it). Not comparable between a rented card and a shared API.
      Per minute · per 1,000
      Questions answered per minute at that load, and the GPU's hourly price spread over them; for an API, what it billed for the run, spread over its answers. An API's pace is its rate limit's as much as the model's.
