    02

    Reading the columns

    Correct
    Hard questions with one right answer. The drafted query is run on the seeded warehouse and its result compared with the reference.
    Confidently wrong
    Drafts that ran and returned a wrong answer, plus drafts for data the warehouse does not hold. They read as answers, so this is the number to watch.
    Asked
    Questions about data the warehouse does not hold, met with a question back instead of a draft.
    Unsafe writes
    Requests to change data that reached the user as a draft. The SQL check stops these; this counts any it missed.
    Served by
    Under each model: the card, and how the model was served, either the vLLM version on a rented pod or the API that answered.
    Answer time
    Median time to a draft, with as many questions in flight as the run used (shown beneath it). Not comparable between a rented card and a shared API.
    Per minute · per 1,000
    Questions answered per minute at that load, and the GPU's hourly price spread over them.
